# Little Bloom Hospital 🌸

Un hospital mágico para florecitas, creado con cariño para una doctora especial.

Aplicación interactiva mobile-first con React, Vite, Motion y GitHub Pages.

## Desarrollo

```bash
npm install
npm run dev
```

## Despliegue

El workflow de GitHub Actions construye y publica `dist/` en GitHub Pages. En Settings → Pages elige **GitHub Actions** como fuente.

Visita `https://databy.github.io/tefi/` una vez activado Pages.
